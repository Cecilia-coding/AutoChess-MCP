# 普攻与技能特效

本包按 `packs/ai/skills.ts` 的技能意图制作视觉表现。Claude 使用橘色系，GPT / Codex 的特效仅使用黑白灰，其他角色沿用自己的主色。普攻比技能更短、更小；技能按护盾、治疗、换形、分弹、贯穿、多段、延迟、控制等类型编排。

## 文件

- `preview/effects.js`：不依赖 DOM 的底层特效与普攻 API，29 套配色。
- `preview/skills.js`：技能名称、语义、分支与多目标视觉编排。依赖 `effects.js`；豆包换形需要先加载 `mascots.js`、`renderer.js`。
- `effects/attacks/ai-*.png`：每角色独立普攻图集，768×288，三行：蓄力、弹道/斩击、命中。每行 8 帧，每帧 96×96，锚点 `(48,48)`。
- `effects/ai-*.png`：技能基础图集，768×384，四行：蓄力、弹道、冲击、护盾环。每行 8 帧，96×96。
- `effects/symbols/ai-*.png`：每角色 14 个状态/技能标记：护盾、治疗、攻击、攻速、射程、牌、沉默、破甲、减速、缴械、模型方块、书页、画框、免控。每格 64×64，锚点 `(32,32)`。
- `effects/manifest.json`：坐标、配色、普攻类别、技能及分支元数据。`effects/contact-sheet.png` 是基础元素的总览。

图集是可以复用的元素；完整技能由源码组合这些元素，不能把所有技能都播放成同一种弹道。图集使用 `progress` 而非固定帧时长：在正式事件持续时间内按 `floor(progress * 8)` 取帧并限制到 0～7。到结束事件应移除特效，避免最后一帧悬停。

## API 示例

按顺序加载 `mascots.js`、`renderer.js`、`effects.js`、`skills.js`。

```js
// 普攻：近战短斩、远程弹道、法术光弹，420 ms 为原型打点。
PixelEffects.draw(ctx, 'ai-claude', {
  kind: 'attack', ageMs: elapsed,
  source: { x: 140, y: 150 }, target: { x: 420, y: 150 },
  scale: 1.5, reducedMotion: false
});

// 技能：GPT 给自己与友军套黑白护盾，不生成对敌攻击弹。
PixelSkills.draw(ctx, 'ai-gpt', {
  ageMs: elapsed, source: { x: 180, y: 150 },
  allies: [{ x: 80, y: 150 }],
  foes: [{ x: 420, y: 150 }, { x: 520, y: 110 }, { x: 516, y: 190 }],
  variant: 0, scale: 2, reducedMotion: false
});
```

API 只画图、不扣血、不选正式战斗目标、不改变棋子状态。坐标是身体中心；友军数组不重复包含施法者。演示里的三木桩用于展示分弹和最远目标。正式接入请直接传引擎事件的目标坐标、技能分支、护盾/控制持续时间；有局部敌人范围时传入引擎已筛选的目标，不能拿演示布局代替引擎选人。

`PixelSkills.spec(id, variant)` 返回技能名、视觉类型、原型时间轴。普通技能原型为 1.8 秒；DeepSeek 保留 1.2 秒沉思，即梦保留 2 秒延迟。原型的动画时长不是正式状态时长：例如克儿护盾实际为 6 秒、免控为 2 秒，应由战斗事件负责移除。状态标记可单独调用 `PixelSkills.drawToken(ctx, id, 'shield', {x, y, scale})` 持续绘制。

普攻增益（Grok / Manus）要绑定后续的普攻事件；技能展示只示意增益和追加路径。Codex 没有新的主动技能，本包展示 GPT → Codex 的被动换形、增攻和攻速标记，普攻使用终端脉冲。头像换形仍由正式 `reskin` 事件决定；预览不会修改 GPT 的实际状态。

## 预览方式

打开 `preview/index.html`。有「普攻一次」「放个技能」「特效开关」、0.25 倍速和三个快捷示例。GLM、Gemini、Mistral 可手动选择技能分支，方便看完所有效果；分支概率和奇偶计数由正式引擎决定。

木桩数值仅演示：普攻扣 18，伤害技能扣 30，护盾/治疗/换形/控制技能不直接扣木桩血。多段技能的 30 只是一次性演示合计，不能复制到正式战斗。八段连击、双目标、范围伤害、治疗和增益的真实数值均使用原引擎事件。

本次覆盖普攻、主动技能与 Codex 换形。商店售罄、查 IP、罢工等局外事件，以及临界血量被动的独立动画尚未制作；不应把它们当作已接入。

## 重导出 / 校验

`npm run export:fx` 重新导出所有特效；`npm run check` 检查网页交互、29 套配色、黑白限制、导出帧、技能名与真实源码一致性、GLM 分支和延迟时机。原来的角色图集与内部 ID 保持可用。
